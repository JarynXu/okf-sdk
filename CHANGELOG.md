## [0.1.0-alpha.1] - 2026-08-05

### Added

- Deterministic OKF bundle and document model.
- Markdown parser with YAML front matter and path-derived document identifiers.
- Structural validation with stable issue codes.
- Directed knowledge graph traversal.
- Deterministic in-memory retrieval with tag filtering.
- Integration tests, example program, format guide, and CI workflow.
